# ✅ Minha Lista de Tarefas

Uma aplicação simples de lista de tarefas desenvolvida com HTML, CSS e JavaScript.

## 📋 Sobre o Projeto

Este projeto permite adicionar tarefas de forma rápida e organizada diretamente no navegador.

Foi desenvolvido como projeto de estudo para praticar:

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages

---

## ✨ Funcionalidades

- ✅ Adicionar tarefas
- ✅ Visualizar tarefas
- ✅ Interface simples e intuitiva
- ✅ Atualização em tempo real

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
